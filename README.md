# Online Shoppers Intention Prediction

## 📌 Project Overview

This project analyzes online shoppers' behavior and predicts whether a visitor will generate a revenue session.

The project combines data analysis, visualization, and machine learning techniques to understand customer behavior and identify the key factors that influence purchasing intention.

## 🎯 Objectives

- Analyze online shoppers' behavior and purchasing patterns.
- Identify the factors that influence purchasing intention.
- Build a machine learning model to predict whether a session will generate revenue.
- Visualize important patterns and insights from the data.
- Develop an interactive Streamlit dashboard for exploring the results.

## 📊 Dataset

The dataset contains information about online shopping sessions, including:

- Administrative features
- Informational features
- Product-related features
- Bounce Rates
- Exit Rates
- Page Values
- Special Day
- Month
- Visitor Type
- Weekend
- Revenue

## 🔍 Key Analysis

The project explores customer behavior and investigates how different session characteristics are related to purchasing intention and revenue generation.

The analysis includes:

- Customer behavior analysis
- Revenue distribution
- Visitor type analysis
- Bounce and exit rate analysis
- Page value analysis
- Weekend and special-day behavior
- Important features affecting revenue prediction

## 🤖 Machine Learning

A machine learning classification model is used to predict whether an online shopping session will generate revenue.

The model is trained using selected features from the dataset and evaluated using appropriate classification metrics.

## 📊 Dashboard

An interactive Streamlit dashboard was developed to provide an easy-to-understand view of the analysis, insights, and prediction results.
